# Loops

Local audio assets for development. Audio files are gitignored.

## Ableton Live export settings (M1)

Export two loops at 120 BPM in 4/4, each 4 bars long. At 48 kHz, one bar is
exactly 96,000 frames.

- **Render Start:** bar 1
- **Render Length:** 4 bars
- **Format:** WAV, 48000 Hz, 24-bit or 32-bit float
- **Render as Loop:** on, so effect tails wrap around to the start
- **Normalize:** off
